About DhanabalMart

Enterprise multi-vendor e-commerce marketplace powered by 100% Pure Java.

Project Vision & Core Principles

DhanabalMart is a production-grade full-stack e-commerce marketplace designed with an emphasis on rock-solid architectural integrity, transactional consistency, and enterprise durability. Built entirely on standard Java enterprise primitives, the application delivers optimal performance, clean maintainability, and effortless deployment to modern cloud infrastructure.

Unlike fragmented heterogeneous application stacks, DhanabalMart unifies authentication, authorization, business domain logic, and presentation within an elegant, typed, server-rendered Java ecosystem with zero JavaScript overhead.

Technology Stack

  • Runtime: Java 17 LTS (Eclipse Temurin)
  • Framework: Spring Boot 3.2.5
  • UI Layer: Thymeleaf 3 + Pure CSS
  • Security: Spring Security 6 (BCrypt, Session + JWT)
  • Persistence: Spring Data JPA / Hibernate 6
  • Database: Relational PostgreSQL (Render managed)
  • Containerization: Multi-stage Docker build

User Roles & Governance

  • Admin: Platform health oversight, seller approval workflow, user account governance, catalog moderation, and financial reporting.
  • Seller: Store storefront management, inventory and pricing control, order tracking, and sales analytics.
  • Buyer: Catalog discovery, full-text search, shopping cart management, seamless checkout, and personal order history.
